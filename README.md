# Clínica Odonto Teste

Site de demonstração da Lume Odontologia, clínica fictícia.

- `index.html`: página principal, com agendamento em três escolhas que monta a mensagem e abre o WhatsApp, simulador de tratamento, antes e depois, tecnologia, equipe, Plano Lume e perguntas frequentes
- `equipe.html`: perfil de cada dentista, com CRO, dias de atendimento, formação, cursos e diplomas
- `styles.css`: visual compartilhado pelas duas páginas

Para usar com uma clínica real:

1. Troque o número em `WHATSAPP` nos dois arquivos HTML.
2. Troque nome, endereço, convênios, preços, nota do Google e fotos.
3. Em `equipe.html`, edite a lista `TEAM` com os dados de cada profissional.
4. Para mostrar a foto de um diploma, salve a imagem numa pasta `diplomas/` e preencha `img` no item, por exemplo `img: "diplomas/helena-graduacao.jpg"`.
