# Clínica Odonto Teste

Site de demonstração da Lume Odontologia, clínica fictícia.

- Agendamento em três escolhas que monta a mensagem e abre o WhatsApp da clínica
- Simulador de tratamento com duração e valor inicial
- Comparador de antes e depois para arrastar
- Seção para quem tem medo de dentista

Para usar com uma clínica real, troque o número em `WHATSAPP` no `index.html`, além do nome, endereço, convênios, preços e fotos.
